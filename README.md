# Python Chat Application 💬
A simple client-server chat application built using **Python and Socket Programming**.  
This project demonstrates real-time communication between a client and a server and stores chat history with timestamps.
## 📌 Features
- Real-time message communication
- Client-Server architecture
- Username support
- Timestamped chat messages
- Chat history storage
- Simple command-line interface
## 🛠 Technologies Used
- Python
- Socket Programming
- File Handling
- Networking Concepts

## ⚙️ How to Run the Project

Step 1: Clone the repository

git clone https://github.com/shivasumedha/python-chat-application.git

Step 2: Navigate to the project folder

cd python-chat-application

Step 3: Run the server

python server.py

Step 4: Run the client (in another terminal)

python client.py
